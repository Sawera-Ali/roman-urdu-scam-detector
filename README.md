# ScamGuard — Roman Urdu SMS Scam Detector

ScamGuard is a machine learning–based web application designed to identify potentially fraudulent Roman Urdu SMS messages. Users can paste a message into the checker and receive a **Scam** or **Authentic** prediction generated by a trained text-classification model.

Along with message detection, ScamGuard provides scam-awareness resources, an interactive Scam IQ quiz, and an analytics dashboard for understanding prediction activity.

---

## Overview

Digital scams are increasingly delivered through SMS and messaging platforms, often using Roman Urdu to target local users.

ScamGuard explores how machine learning can be used to analyze these messages and distinguish potentially fraudulent content from authentic communication.

The application focuses on **binary text classification**:

- **Scam**
- **Authentic**

ScamGuard is designed as a message-analysis tool. It does not intercept, monitor, or automatically block SMS messages on a user's device.

---

## Key Features

### SMS Scam Checker
Users can paste a Roman Urdu SMS into the application and analyze it using the trained machine learning classifier.

### Machine Learning Classification
Messages are processed and transformed into numerical features before being passed to the trained model for Scam vs Authentic classification.

### Prediction Confidence
Where supported by the production model, ScamGuard displays the model's probability-based confidence alongside the prediction.

### Analytics Dashboard
The dashboard summarizes real prediction activity recorded by the application, including:

- Total messages analyzed
- Scam detections
- Authentic detections
- Scam vs Authentic distribution
- Recent scan activity
- Available confidence statistics

Dashboard values are calculated from actual prediction history rather than hardcoded demonstration values.

### Scam IQ
An interactive quiz that helps users test their ability to recognize suspicious messages and common scam warning signs.

### Scam Guide
Provides practical awareness information to help users recognize suspicious messages and make safer decisions when encountering possible scams.

### Privacy-Conscious Analytics
The analytics system stores only the metadata required for statistics. The actual SMS text entered by users is not stored in scan history.

## How It Works

The core prediction pipeline follows this process:

```text
Roman Urdu Message
        ↓
Text Preprocessing
        ↓
Feature Vectorization
        ↓
Trained ML Classifier
        ↓
Scam / Authentic Prediction
        ↓
Result & Analytics
```

The message is cleaned and prepared using the project's preprocessing pipeline. It is then transformed using the trained vectorizer and passed to the machine learning model for classification.

---

## Machine Learning

ScamGuard uses supervised machine learning for **binary text classification**.

During development, multiple classification approaches were explored, including:

- Logistic Regression
- Naive Bayes
- Support Vector Machine (SVM)

The web application uses the repository's trained production model and corresponding vectorizer for inference.

The classifier predicts whether an entered message belongs to the **Scam** or **Authentic** class.

> **Note:** ScamGuard's core model performs binary classification. It does not claim to perform trained multiclass classification of scam categories such as banking scams, lottery scams, or OTP scams.

## Analytics Dashboard

ScamGuard includes an analytics dashboard connected to actual application predictions.

Each successful prediction can contribute privacy-safe metadata to the local analytics history.

For example:

```text
Total Scans:       50
Scam Detected:     32
Authentic:         18
```

The dashboard calculates its statistics dynamically from stored prediction records.

The application does not fabricate scam-category predictions or treat model confidence as a separate trained risk-severity model.

---

## Privacy

ScamGuard is designed to avoid unnecessarily storing message content.

The local analytics system can retain information such as:

```text
Prediction
Confidence
Timestamp
Scan ID
```

The actual SMS text entered into the checker is not stored as part of the analytics history.

This allows the dashboard to calculate useful statistics without maintaining a history of users' private messages.

## Limitations

ScamGuard is an ML-based detection system and its predictions should be treated as decision-support information rather than guaranteed fraud verification.

- The current model performs **binary Scam vs Authentic classification**.
- It does not perform trained multiclass scam-category classification.
- Model probability/confidence should not automatically be interpreted as calibrated real-world risk.
- Classification quality depends on the training data and how closely new messages resemble patterns represented in that data.
- JSON analytics are suitable for local development and demonstration but are not intended to replace a production database.
- Persistent analytics on serverless deployments require an appropriate persistent storage solution.
